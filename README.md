# 🏒 Knee Hockey League

Scores, standings, live games and tournament brackets for Jaxon and the crew, in Lafayette Locomotives colors.

- Open `index.html` in a browser. There's no build step.
- Hosted on GitHub Pages. Shared league data lives in Firebase Firestore (see `CLAUDE.md`).
- Backup of the league data: `data/league-export.json`.

**Features:** overall and per-season standings, power rankings, live game clock with goal horn and jumbotron intro, player scoring leaders and hat tricks, knockout and round-robin tournaments with auto-built brackets, team pages with trophy case and head-to-head, custom seasons with their own dates and points rules.
